# OCR 原文排版对比设计

日期：2026-08-03

## 1. 目标

在审核工作台中以原始 PDF 页面作为底图，叠加 OCR 识别文字块和问题证据框，帮助业务人员和法务快速判断识别结果是否与原文排版一致。原始合同文件始终保持不变，OCR 仅用于检索、定位、风险说明和差异标注。

## 2. 范围

本次增加原文叠加模式，不建设完整的 OCR 文档编辑器或自动修改合同内容。支持合同、法审签报、合同签批文件、事项签报/会议纪要和其他已解析材料。

核心能力：

1. 展示当前材料指定页的原始页面图。
2. 按 OCR 坐标在原始页面上绘制文字块边框。
3. 使用置信度显示识别质量：高置信度绿色、中等黄色、低置信度红色。
4. 对问题证据使用独立高亮色，并在点击问题时自动定位到对应页面和文字块。
5. 点击 OCR 框或文本块后同步选中对应识别内容。
6. 支持显示全部识别框和仅显示问题相关框两种模式。
7. 历史材料没有页面图时按需生成页面图，不要求用户重新上传。
8. 页面图接口按案例、文件和页码校验归属，不暴露本机绝对路径。

## 3. 方案与边界

采用服务端页面渲染和前端坐标叠加：

- 服务端使用已有 PDF 渲染能力为每页生成 PNG，并保存到当前案例的受控存储目录。
- 图片文件使用数据库中的页面记录关联，前端通过受保护的页面图片接口读取。
- 前端保持原始页面的宽高比例，OCR 坐标使用页面原始尺寸绘制，再由 CSS 等比缩放。
- 对 PNG/JPG 等图片材料，直接复制原图或生成统一页面图作为底图。
- 对纯文本材料没有可视化页面图时，保留现有 OCR 文本列表作为降级展示。

不采用浏览器直接读取本地 PDF 路径的方案，避免跨平台路径、浏览器 PDF 渲染坐标和本机文件暴露问题。

## 4. 后端设计

### 4.1 页面图生成

扩展文件解析入库流程：

- PDF 文件为每页生成原始 PNG，同时记录页面宽度和高度。
- 扫描 PDF 的 OCR 继续使用预处理后的图片识别，但底图使用未预处理的原始页面图，避免排版和颜色变化。
- 图片文件以原始图片作为底图，记录宽高。
- 页面图放置在 `storage/cases/{case_id}/pages/{file_id}/` 目录下，文件名使用固定页码格式。
- 重复解析时覆盖当前文件页面图和 OCR 页面记录，旧审核版本仍通过版本号保存问题结果。

### 4.2 页面图片接口

新增页面图片读取接口，输入案例 ID、文件 ID 和页码：

1. 校验案例存在且未删除。
2. 校验文件属于案例。
3. 校验页码对应数据库页面记录。
4. 解析页面图路径并确认路径位于配置的存储根目录下。
5. 页面图缺失时触发一次按需生成，生成失败返回可识别的 404/422 错误。
6. 使用 `FileResponse` 返回图片，不返回原始上传文件绝对路径。

文档列表接口继续返回页面宽高、OCR 状态和文字块坐标；前端根据案例 ID、文件 ID、页码拼接页面图接口地址。

## 5. 前端设计

在现有 `EvidenceViewer` 页面预览区域增加原文叠加层：

- 页面容器使用原始页面图确定尺寸。
- OCR canvas 与图片使用同一定位容器、同一原始宽高。
- 框颜色按置信度显示；问题引用框使用橙红色并覆盖置信度颜色。
- 当前聚焦块增加较粗边框和轻微闪烁定位状态，避免仅依赖颜色。
- 增加“显示全部识别框 / 仅显示问题框”切换。
- 页面图加载失败时展示错误状态和现有文本块列表，不阻断审核。
- 点击 OCR 框后滚动至对应文本块并显示文本、页码、置信度和坐标。
- 点击左侧问题或证据卡片后同时切换材料、页码和对应 OCR 框。
- 仍支持人工标记，人工标记不修改 OCR 原文和底图。

## 6. 数据流

1. 文件上传后保存原始文件。
2. 解析器提取 PDF 文字层或执行 OCR，并生成页面图。
3. 文件入库服务写入页面宽高、页面图相对路径和 OCR 块坐标。
4. 审核工作台获取文档、问题和证据引用。
5. 页面图片接口返回当前页原始底图。
6. 前端将 OCR 坐标转换为当前显示尺寸并叠加绘制。
7. 问题导航根据证据引用更新当前文件、页码和块高亮。

## 7. 错误处理与安全

- 页面图缺失、生成失败或 OCR 没有坐标时，降级到文本列表，不显示误导性框。
- 不允许通过 `../`、绝对路径或任意 `image_path` 读取存储根目录之外的文件。
- 不把上传文件真实路径、系统用户名或临时目录返回给前端。
- 页面图片响应使用正确 MIME 类型，并保留现有案例归属校验。
- 页面图生成失败不改变已成功保存的 OCR 文本和审核结果。

## 8. 测试与验收

后端：

- PDF 页面图生成后保存页面宽高和路径。
- 图片材料可作为页面底图。
- 页面图片接口可读取所属案例页面。
- 跨案例文件、非法页码和路径穿越请求被拒绝。
- 历史页面图缺失时按需生成或返回明确降级状态。

前端：

- 原文图片和 OCR 叠加层尺寸一致。
- 置信度和问题高亮颜色正确。
- 点击问题能定位文件、页码和 OCR 块。
- 切换显示模式不会影响问题定位。
- 图片加载失败时仍可查看 OCR 文本。

验收标准：打开扫描合同问题时，用户可以在原始页面上直接看到对应 OCR 框；点击问题后自动跳转至正确页和位置；刷新页面后状态和定位仍可恢复；原始文件内容不被修改。
